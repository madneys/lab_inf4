# Справочник: Системы счисления

**Тема:** Позиционные и непозиционные системы счисления, перевод чисел и арифметика.  
**Цель:** Сформировать базовые знания о представлении числовой информации в ЭВМ для первокурсников.  
**Автор:** @Madenys

## Структура проекта
* `README.md` — описание проекта и руководство по чтению.
* `glossary.md` — словарь ключевых терминов по системам счисления.
* `examples.md` — практические примеры перевода и вычислений.
* `sources.md` — список использованных источников.
* `questions.md` — вопросы для самопроверки.

## Инструкция по изучению справочника
1. Ознакомьтесь с терминологией в файле `glossary.md`.
2. Изучите алгоритмы на примерах в `examples.md`.
3. При необходимости обратитесь к источникам из `sources.md`.
