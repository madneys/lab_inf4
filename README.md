# Справочник: Системы счисления

**Тема:** Позиционные и непозиционные системы счисления, перевод чисел и арифметика.  
**Цель:** Сформировать базовые знания о представлении числовой информации в ЭВМ для первокурсников.  
**Автор:** @madneys

## Структура проекта
* [`README.md`](README.md) — описание проекта и руководство по чтению.
* [`glossary.md`](glossary.md) — словарь ключевых терминов по системам счисления.
* [`examples.md`](examples.md) — практические примеры перевода и вычислений.
* [`sources.md`](sources.md) — список использованных источников.
* [`questions.md`](questions.md) — вопросы для самопроверки.

## Как пользоваться справочником
1. Ознакомьтесь с терминологией в файле [`glossary.md`](glossary.md).
2. Изучите алгоритмы на примерах в [`examples.md`](examples.md).
3. При необходимости обратитесь к источникам из [`sources.md`](sources.md).
4. Проверьте себя по вопросам из [`questions.md`](questions.md).
